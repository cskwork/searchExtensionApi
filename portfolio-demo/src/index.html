searchExtensionApi 탐색기

원본 Spring Boot 블로그 검색 API 의 엔드포인트, 파라미터, 응답 형식, 오류 코드를 그대로 따르는 모의 어댑터로 요청을 보내 봅니다. Java 백엔드는 여기에 배포되지 않았고, 모든 응답은 이 브라우저 안에서 만들어집니다.

요청 GET /search

빈 칸은 파라미터를 보내지 않은 것으로 처리합니다. 범위 밖 값이나 숫자가 아닌 값도 그대로 보내 오류 응답을 확인할 수 있습니다.
