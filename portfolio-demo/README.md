# 검색 API 실험실

원본 Java 계약을 추출한 정적 API 탐색기다. `src/app.js`, `src/index.html`, `src/styles.css`가 실제 화면 소스이며 `generated/contract.js`는 추출 명령으로만 갱신한다. `index.html`은 외부 요청 없는 모의 환경이고, `live.html`은 실제 Spring 서버가 같은 출처에서 제공하는 원본 API에 연결한다.

## 실행과 검사

```sh
npm ci
npm run check:contract
npm run test:all
```

DOM 검사는 잠금 파일에 고정된 테스트용 jsdom으로 실제 앱 소스와 클릭·키보드 이벤트를 실행한다. 공개 결과물에는 jsdom이 포함되지 않으며 브라우저 렌더링 검사를 대신하지 않는다.

## 체험 흐름

- 정상·카카오 장애·모두 장애·잘못된 입력 버튼은 입력을 채우고 바로 모의 요청을 실행한다.
- 결과·JSON·처리 흐름 탭은 좌우 방향키/Home/End로 이동한다. 실행하면 응답 제목에 초점을 두고 작은 화면에서는 응답으로 이동한다.
- 최근 5건에는 요청 설정과 HTTP 상태·공급자·메시지를 보관한다. '설정 불러오기'는 실행하지 않고, '다시 실행'은 저장된 설정으로 새 요청을 실행한다. 성공 요청마다 기존 규칙대로 검색 횟수가 1 증가한다.
- 새로고침하면 마지막 입력·공급자 설정과 최근 이력만 복원한다. 자동 재실행·응답 복원·통계 증가가 없다. 인기 검색어와 이력은 별도 키를 쓴다. 이력을 지워도 인기 검색어는 유지한다.
- 다음/이전 페이지는 현재 응답을 만든 요청·공급자 설정을 사용한다. 입력칸을 고친 뒤에도 기존 응답과 다른 공급자로 조용히 바뀌지 않는다.
- 실패의 '정상 설정으로 복구 실행'은 검색어를 유지하고 정상 공급자·기본 페이지/크기로 실행한다.

## 제품·디자인 경계

요청과 응답이 먼저 보이는 실험 도구다. 결과/JSON/처리 흐름을 한 영역에서 전환하고 긴 계약표·출처는 접힌 참고 영역에 둔다. 흰 작업면과 진회색 코드 영역, 파란 주 액션을 사용한다. 소비자용 블로그 검색 서비스나 실제 장애 모니터가 아니다.

원본 HTTP 401/402/501과 payload를 유지한다. 네이버 시작 위치는 `(page - 1) * pageSize + 1`로 수정했으며 갱신한 계약 출처 해시를 검사한다. 탐색기 이력은 UI 편의 기능이며 API 계약에 필드를 추가하지 않는다. 설정·이력 손상은 기본값으로 복구하고 저장소를 쓸 수 없으면 메모리 유지 사실을 알린다. 공개 빌드는 명시적 허용 파일만 포함한다.

이번 변경의 실제 desktop/mobile 레이아웃·스크린리더·브라우저 동작 검증과 배포는 사용자 요청으로 보류했다.

실제 서버 재현과 공급자 설정은 [NATIVE-RUNBOOK.md](../NATIVE-RUNBOOK.md)를 참고한다. 실제 연결 실패를 모의 응답으로 바꾸지 않으며, 이력은 모드와 서버별로 분리한다.
